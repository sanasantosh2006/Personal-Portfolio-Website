# 🌐 Personal-Portfolio-Website
# Project Overview
A modern, fully responsive Personal Portfolio Website built using HTML5, CSS3, and JavaScript. This portfolio is designed to showcase personal information, skills, projects, achievements, certifications, and contact details with a clean and professional user interface.
# 🚀 Features
🏠 Responsive Home Section
👤 About Me
🛠️ Skills with Progress Bars/Cards
📂 Projects Showcase
🏆 Achievements & Certifications
📞 Contact Form (Frontend)
🌐 Social Media Links
📄 Resume Download Button
📱 Fully Responsive Design
✨ Smooth Navigation and Modern UI
# 🛠️ Technologies Used
